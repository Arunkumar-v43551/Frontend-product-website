# NOVA – Premium SaaS Landing Page

![NOVA Hero Preview](https://via.placeholder.com/1200x600/111111/FFFFFF?text=NOVA+SaaS+Platform)

> **Note:** This project was developed as a Front-End Development Internship Assignment to demonstrate proficiency in modern web architecture, UI/UX design, and complex animations.

## 📖 Project Description

NOVA is a fictional AI-powered productivity platform that helps modern teams manage projects, automate repetitive work, analyze workflows, and collaborate efficiently. 

This project is a complete, production-quality SaaS landing page designed to feel premium and state-of-the-art. It moves beyond standard UI tutorials by incorporating custom-built SVG charts, live-ticking data counters, class-based dark mode architecture using CSS variables, and advanced scroll-triggered physics animations.

## 🚀 Features

- **Advanced Theming Architecture**: Custom implementation of light and dark mode using Tailwind CSS v4 and native CSS variables. The light mode features a sharp, monochrome black-and-white aesthetic, while the dark mode shifts into a vibrant, glowing purple theme.
- **Custom Animated SVG Charts**: Built highly-optimized, dependency-free React SVG components for line and bar charts. Features CSS `stroke-dasharray` drawing animations and staggered `scaleY` bar growth.
- **Live Telemetry Simulation**: Number counters that act as "live" dashboard metrics, randomly fluctuating to simulate real-time enterprise data.
- **Physics-Based Scroll Animations**: Integrated `motion` (Framer Motion) for complex, physical "card popping" effects tied to the user's scroll position.
- **Infinite Marquee**: Seamless, continuous horizontal scrolling logo cloud with gradient edge masking.
- **Responsive Bento Grids**: Modern asymmetrical layouts that elegantly stack on mobile viewports.

## 💻 Technologies Used

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) (Fast refresh and optimized bundling)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (Using modern `@custom-variant` architecture)
- **Animations**: [Motion](https://motion.dev/) (Framer Motion v12) & Native CSS Keyframes
- **Icons**: [Lucide React](https://lucide.dev/)
- **State Management**: React Hooks (`useState`, `useEffect`, `useRef`) + `IntersectionObserver`
